# Daily News Bootstrap

Responsive Daily News landing page built for Laboratory Work 1–2 with Bootstrap 5.3.7, Font Awesome, and the required Bootstrap grid sections.

## Run locally

Open `index.html` in a browser. An internet connection is required for Bootstrap, Font Awesome, Google Fonts, and the Unsplash photographs.

## Included layout

- Responsive top bar, masthead, navigation and search
- Featured article, Latest News cards and desktop sidebar
- Must Read and Popular News responsive grids
- Three-column footer and newsletter form
- Search filtering for the Latest News cards

## Deployment

The static files can be published with GitHub Pages from the repository's `main` branch and root folder.
