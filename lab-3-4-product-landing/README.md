# Awesome Product — Bootstrap 5 Landing Page

Responsive product landing page for Laboratory Work 3–4. Built with Bootstrap 5.3.7 utilities and components, Bootstrap Icons, custom CSS, and a small JavaScript file for ScrollSpy, FAQ state, and demo form feedback.

## Files
- `index.html` — complete page and component markup
- `styles.css` — responsive presentation and custom finishing styles
- `script.js` — ScrollSpy, FAQ accessibility state, and local demo form feedback

## Sections
Navigation, Hero, About, Features, Pricing, FAQ, Contact, Newsletter, and Footer.

The contact and newsletter forms are front-end demonstrations and do not submit data to a server.
