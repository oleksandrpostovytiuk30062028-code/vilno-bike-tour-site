# Вільно — адаптивний сайт велопрогулянок

Статичний сайт українською мовою для сервісу міських велопрогулянок. Зібраний без збирача та зовнішніх залежностей.

## Структура

- `index.html` — семантична розмітка головної сторінки
- `styles.css` — desktop, tablet та mobile стилі
- `script.js` — доступне мобільне навігаційне меню
- `.github/workflows/pages.yml` — автоматична публікація на GitHub Pages після push до `main`

## Додаткова сторінка

Лабораторна робота з Bootstrap 5 «Daily News» розміщена окремо в папці [`lab-1-2-daily-news`](lab-1-2-daily-news/). Це адаптивний макет новинного порталу з Grid System, блоками новин, сайдбаром і підвалом.

## Локальний перегляд

Відкрий `index.html` у браузері або запусти будь-який локальний статичний сервер з цієї папки.

## Публікація на GitHub Pages

1. Додай файли цієї папки до репозиторію GitHub.
2. У репозиторії відкрий **Settings → Pages** і вибери **GitHub Actions** як джерело публікації.
3. Workflow опублікує сайт після push у гілку `main`. Публічне посилання з'явиться в налаштуваннях Pages.
